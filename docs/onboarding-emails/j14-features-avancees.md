# Email J14 - Features avancees (post-paiement)

**Trigger** : 14 jours apres creation du tenant
**Delai** : J0 + 14 jours
**Conditions** :
- compte toujours actif
- client a souscrit (donc paye apres l essai)

---

## Subject

`5 features avancees a debloquer cette semaine`

## Preheader

`Custom prompt, notifs Telegram, auto-reply commentaires... voici comment maximiser ton bot.`

## Corps

```
Salut {{prenom}},

Tu utilises Valina-Bot depuis 2 semaines. Merci pour la confiance.

Voici 5 features que tu n as probablement pas encore explorees :

1. Custom prompt : adapte le ton du bot a ta marque

   Dashboard > Configuration > Prompt personnalise.
   Exemple : "Tu reponds toujours en commencant par bonjour, sur un ton
   amical, en utilisant souvent les expressions ehe et marina daholo."

2. Detection commande automatique

   Le bot peut prendre la commande complete (produit + adresse + telephone
   + paiement) sans intervention humaine. Active dans Configuration >
   Workflow.

3. Notifications Telegram pour les prospects chauds

   Recois une alerte instantanee quand un client manifeste l intention
   d acheter. Tu peux le rappeler en 5 min au lieu d attendre que le bot
   gere seul.
   Configuration > Notifications.

4. Reponses aux commentaires en prive

   Le bot peut repondre automatiquement en DM aux commentaires sous tes
   posts (ideal pour les lives ou les posts qui font polemique).
   Configuration > Auto-reply commentaires.

5. Test bot en direct

   Avant de modifier ton catalogue ou ton prompt, teste avec un message
   simule. Configuration > Test bot. Tu vois la reponse en direct sans
   risquer de servir un mauvais message a un vrai client.

Reponds a ce mail si tu veux qu on programme un appel de 15 min pour
optimiser ton setup ensemble. Pas de cout, juste 15 min pour s assurer
que tu utilises toute la valeur du produit.

Manda

---
contact@valina-bot.com
```

## Notes

- Liste de 5 features concretes avec chemin precis dans le dashboard
- Offrir 15 min d optimisation gratuite : c est ton meilleur moyen de
  fideliser un client paye en mois 1
- Eviter la tonalite "promotion" (pas une newsletter), c est un email de
  customer success
