# Email J3 - Check-in (3 jours apres signup)

**Trigger** : 72h apres creation du tenant
**Delai** : J0 + 72h
**Conditions** : compte toujours actif

---

## Subject

`Comment ca se passe avec Valina-Bot ?`

## Preheader

`Reponds par 1, 2 ou 3. Je m occupe du reste.`

## Corps

```
Salut {{prenom}},

Ca fait 3 jours que ton bot tourne sur {{nom_page}}.

J aimerais savoir : comment ca se passe ?

Reponds-moi simplement par 1, 2 ou 3 :

1. Tout marche super bien

2. Ca marche mais j aimerais te poser quelques questions

3. J ai un probleme ou ca ne marche pas comme prevu

Selon ta reponse, je t envoie ce qu il faut :
- Une video tuto si tu veux optimiser
- Une demo perso de 15 min
- Ou on regle le probleme ensemble

Pas de jugement, je veux juste que tu reussisses.

Manda

---
contact@valina-bot.com
```

## Notes

- Email tres court (~80 mots) — l objectif est la reponse, pas la lecture
- Format 1/2/3 : aucune friction de reponse
- Tres important : repondre a TOUS dans les 24h
- C est l email avec le meilleur taux de feedback de toute la sequence
- Si pas de reponse en 24h : envoyer un follow-up "Je t ai laisse un
  message hier, tout va bien ?"

## Reponse type a chaque case

### Si client repond "1"
```
Super ! Tu fais quoi de plus ?
Si tu connais d autres commercants qui galerent avec leurs reponses
Messenger, parle-leur de Valina-Bot. Je te file 1 mois gratuit pour chaque
filleul qui passe en plan paye.
Manda
```

### Si client repond "2"
```
Excellent. Pose-moi tes questions, je reponds dans la journee.
Manda
```

### Si client repond "3"
```
On regle ca tout de suite. Tu as 5 min ? Envoie-moi ton numero, je
t appelle. Ou si tu preferes ecrit, decris-moi le probleme.
Manda
```
